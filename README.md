# WaterPulse — 실데이터 사전 시뮬레이션 결과

비가 오면 댐에는 몇 시간 뒤에 물이 가장 많이 몰려올까?
K-water 댐·보 59곳의 2020–2025년 시간 자료로 확인한 결과 화면입니다.

- 페이지: https://keemlogan.github.io/waterpulse/
- 자료: 공공데이터포털 한국수자원공사 수문 운영 정보 · 우량수위 관측소 운영 정보 · 수문 제원 현황 (2026-10-05 호출)
- 이 저장소에는 화면 코드와 분석 결과 요약(`data/summary.json`)만 있습니다. 원본 데이터와 인증키는 올리지 않았습니다.

ITM 527 빅데이터실무 팀 프로젝트 사전 시뮬레이션입니다. 빌드 도구 없이 정적 파일 세 개(`index.html`, `style.css`, `app.js`)로 동작합니다.
