# WaterPulse — 실데이터 사전 시뮬레이션 결과

비가 오면 댐에는 몇 시간 뒤에 물이 가장 많이 몰려올까?
K-water 댐·보 59곳의 2020–2025년 시간 자료로 확인한 결과 화면입니다.

- 프로젝트 허브: https://keemlogan.github.io/waterpulse/hub/ — 과제 요구사항, 단계별(수집·적재·전처리·저장·분석·웹) 할 일과 방법, 일정, 문서
- 페이지: https://keemlogan.github.io/waterpulse/
  - 분석 결과: 댐별 반응 시간, 유역 넓이 비교, 상류 관측소 효과, 20년 큰물 지수
  - 방류 계산기 (`release.html`): 과거 큰비 시점으로 되감아, 12시간 동안 얼마나 내보내야 했는지 계산하고 댐 단면 움직임으로 보여 줌
  - 재난 상황판 (`alert.html`): 같은 시점에 모든 댐의 지금 수위와 12시간 안 예상 최고 수위로 위험·경계·정상을 판정하고, 실제 결과와 맞춰 봄
- 되감기 예측은 그 해 자료를 보지 않고 다른 해로만 배운 모델로 만들었습니다(2020년 시점 → 2023–2025년 모델, 2023–2025년 시점 → 2020–2022년 모델).
- 교육용 시뮬레이션입니다. 실제 방류·재난 판단에 쓰지 마세요.
- 자료: 공공데이터포털 한국수자원공사 수문 운영 정보 · 우량수위 관측소 운영 정보 · 수문 제원 현황 (2026-10-05 호출)
- 이 저장소에는 화면 코드, 분석 결과 요약(`data/`), 허브(`hub/`), 시뮬레이션 코드(`code/`)만 있습니다. 원본 데이터와 인증키는 올리지 않았습니다. `code/`의 스크립트는 저장소 밖의 `.env`에서 키를 읽습니다.
